- 产物：`home.png`，AI 生成的高保真视觉概念图，不是已开发页面截图。
- 工具：内置 image_gen；完整原始提示词保存在 `home-prompt.txt`。
- 方向：暖白背景、深墨绿文字、青绿色强调、编辑式排版、轻量 Go 代码窗口。

- 重点：先个人定位，再精选文章与专栏，最后最新内容；阅读和内容组织优先。

- 覆盖范围：桌面首页视觉方向；不包含移动端、详情页、后台页面及交互状态验证。
- 后续实现：按 PRD 的排版、响应式、可访问性及状态约定落地。图片本身不能证明可访问性达标。
