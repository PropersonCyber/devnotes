# DevNotes 全站 UI 设计规范

版本：v0.3 · 2026-11-11。以用户确认的 [蓝白与银色概念图](approved-reference.png) 为全站视觉基线，替代此前墨绿方案。

## 本次交付

`preview.html` 是可离线打开的静态设计预览，顶部下拉框可切换 12 个页面。`layout.css` 为设计基线，`preview.js` 为示例内容与预览交互。效果图存放在 `screens/`，从实际 HTML 渲染获得。

仅提供设计与模拟交互，不接入 Go API。搜索文章和后台状态筛选操作内存中的样例；保存、发布、登录等按钮提示尚未连接后端；编辑器预览是固定排版示例，不宣称能实时解析正文。

## 最小宽度：1280px

按照本次需求，整体版面不再针对窄屏压缩。

| 项目 | 规则 |
| --- | --- |
| 页面整体 | `min-width: 1280px`，含阅读站、登录和后台 |
| 公开内容区 | 固定宽度 1200px，水平居中 |
| 1280px 窗口 | 内容两侧各 40px |
| 1440px 窗口 | 内容两侧各 120px |
| 大于 1440px | 继续增加外围留白，内容不无限拉宽 |
| 小于 1280px | 页面仍按 1280px 排版，浏览器产生横向滚动 |
| 阅读页 | 正文固定 760px，目录 240px，间距 72px，总宽 1072px |
| 普通列表页 | 主栏 852px + 间距 32px + 侧栏 316px |
| 三列卡片 | 在 1200px 内容区内等分，间距 24px |
| 管理后台 | 侧栏固定 224px，主区左右内边距 40px，页面保留 1280px 下限 |
| 文章编辑 | 发布设置固定 280px，编辑区使用剩余空间，间距 24px |

这里的“不压缩”指浏览器窗口变窄时不触发缩字、改单栏、隐藏侧栏或整体缩放。浏览器自身的页面缩放功能仍保持可用。

实现约束：

```css
:root {
  --page-min-width: 1280px;
  --content-width: 1200px;
}
html { overflow-x: auto; }
body { margin: 0; min-width: var(--page-min-width); }
.container { width: var(--content-width); margin-inline: auto; }
button { white-space: nowrap; flex-shrink: 0; }
```

不要使用 `overflow-x: hidden` 掩盖溢出，也不要给整个页面加 `transform: scale()` 或 `zoom`。代码块和宽表格可在自身区域滚动，图片仍可设置 `max-width:100%` 防止破坏正文。

此规则替代 PRD v0.1 的 320px 单栏响应式目标。窄屏访问会横向滚动，这是本次明确取舍；不再声称 200% 缩放或手机视口下达到无水平滚动的重排要求。焦点、文字对比度、键盘操作仍须验证。

### 排版与视觉分配

- 首页与项目页：110px（项目）/96px（首页）英文大标题、紧凑行高；蓝色作品区与银色括号形成主要视觉重心。
- 文章/专栏入口：76px 英文标题，中文说明负责解释内容；大标题只用于入口页。
- 阅读页：46px 中文标题，17px / 1.85 正文，深灰代码块；不用 3D 背景干扰长文。
- 后台：30px 标题、白灰输入区、蓝色主操作；保留高密度内容管理布局，不堆放装饰。
- 字体：英文大标题 Arial / Helvetica 粗体，中文 PingFang SC / Microsoft YaHei，辅助标签与代码使用系统等宽字体。
- 色彩重心：大面积浅灰与黑字；每个公开入口只设一个主要蓝色焦点。蓝色区使用白字，标签显示文字状态。
- 导航：活动项用蓝色圆点配合文字字重区分，细分隔线；主按钮方正，作品区保留约 12px 圆角。
- 项目展示：蓝色面板内的浏览器用真实 HTML/CSS 构建，配透视和阴影；全部按钮仍是可点击链接，不把整页概念图当成网页。
- 银色素材：`assets/chrome-brackets.png`，根据确认图通过内置 image_gen 生成，带实际透明通道；[原始提示词](assets/chrome-brackets-prompt.txt)。仅放置于首页、项目页与关于页视觉区。
- 动效：链接使用轻微颜色变化，圆形箭头 hover 旋转；尊重减少动态效果设置，不自动播放大幅运动。

## 开发时补齐的状态

- 列表 loading：保留列表宽度和分隔，使用骨架；空结果提供清空筛选；失败提供重试。
- 文章详情：404 展示“文章不存在或暂未公开”，返回文章列表；不暴露草稿信息。
- 登录：授权中禁止重复提交；取消后可重新登录；非管理员显示拒绝原因和返回入口。
- 编辑：保存中、已保存、保存失败、未保存离开提醒；发布错误定位字段；409 冲突保留输入。
- 上传：进度、格式/体积错误、失败重试；删除标签前提示引用限制。
- 暂无独立错误态效果图，以上按 PRD 验收落地，不把静态截图当作交互实现。

## 与当前工程的关系

本次仅新增 `docs/design` 的原型及效果图，并更新 PRD 的宽度规则。工作区已有未提交的 `apps/web` 首页实现与 `docs/adr`，未被本次修改。正式应用尚未接入这些新页面，也尚未应用 1280px 最小宽度；接入时应统一替换旧的小屏断点规则。
